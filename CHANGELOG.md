# Changelog

## 1.0.0 - 2026-08-16

- Initial public release under `io.github.davidojedalopez.fear-greed`.
- Show the latest CNN US stock-market index as a gauge.
- Show four historical comparison values without progress bars.
- Persist a strict 24-hour request limit and last-good cache across restarts.
- Open CNN's official source page from the bar and panel.
- Add keyboard panel behavior, bounded response validation, tests, and release
  documentation.
